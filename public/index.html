Configurar o acesso aos bancos

  1. Crie uma conta em dashboard.pluggy.ai.
  2. Em Applications, use Go to production para criar a aplicação de bancos reais. Aplicações em Development só mostram conectores de teste.
  3. Crie um arquivo .env nesta pasta com PLUGGY_CLIENT_ID e PLUGGY_CLIENT_SECRET.
  4. Em Customization, habilite as instituições que devem aparecer no widget.
  5. Reinicie o servidor com python server/app.py e clique em Conectar banco.

Sem banco real: os conectores de teste usam usuário user-ok, senha password-ok e token 123456.
